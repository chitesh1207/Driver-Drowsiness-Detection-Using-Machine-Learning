## Objective

Develop a low-cost, non-invasive architecture that observes visible driver-fatigue indicators and generates an audible warning.

## Problem addressed

The system focuses on visible signs such as:

- difficulty keeping the eyes open;
- yawning;
- frequent blinking;
- loss of concentration;
- head nodding;
- slow or swaying head movement.

## Proposed architecture

Camera → preprocessing and feature extraction → Face Mesh analysis → embedded Raspberry Pi decision system → sound alert.

## Reported result

- 97.5% accuracy in the straight-face position
- approximately 3 seconds response time
